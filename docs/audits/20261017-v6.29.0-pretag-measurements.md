# v6.29.0 pre-tag measurements

The readings behind the v6.29.0 release notes, with the tree, date and corpus of each. All on this
machine (Ubuntu 26.04.1, Node 26 unless stated), 2026-10-17 UTC. LLM keys unset and
`CLAUDE_CODE_PATH=/nonexistent` everywhere except the two A/Bs, which ran real `claude -p` legs.
Raw rows that hold whole model replies are not committed.

`119ec07b` (this release's product code; the release commit adds only version files and docs),
